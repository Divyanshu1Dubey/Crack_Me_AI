For each bundle, the importer:
1. Detects per-page scan status.
2. Extracts embedded images via `fitz.get_images()`.
3. Renders pages to PNG at 200 DPI for OCR fallback.
4. Runs the regex question/option/answer/explanation parser.
5. Maps every question to the bundle's primary subject + finer topic hierarchy.
6. Stores every image with hash + OCR + caption placeholder.

# CrackCMS Blog — 100-Article Content Roadmap

This roadmap covers 100 SEO-targeted blog posts for `cracklabs.app`,
organised by **category cluster** (each cluster owns a pillar page on
the site) and **search intent**. Every post is sized to be a real
article — not a stub — and is tagged to the same `BlogPost` type the
blog already ships with, so each one slots into the registry with
zero engineering work.

## How to read the table

- **Cluster** → the hub page (category) the post lives under; drives
  internal linking pass.
- **Primary keyword** → optimise the title, H1, slug, meta description
  around this.
- **Search intent** → I (informational), C (commercial — compare
  CrackCMS vs alternatives), N (navigational — branded).
- **Difficulty** → beginner / intermediate / advanced.
- **Conversion lens** → what helpful CTA fits the post (V1 = "Practise
  N PYQs", V2 = "Open the AI tutor", V3 = "Read the related guide").
- **Outbound link** → the canonical CrackCMS asset this post should
  point to (already exists unless marked `[build]`).

## Production cadence

To stay within Google's quality thresholds, ship **2 posts per week**:

- Mon: write.
- Tue: clinical review by the CrackCMS editorial panel.
- Wed: copy-edit + add TOC + references + revision log.
- Thu: ship; auto-included in sitemap + RSS + category archives.
- Fri: index-check in Search Console + repurpose as a LinkedIn / Twitter
  thread (drives external links).

At 2/week = 100 posts takes ~12 months. By Q2 2027 you should be
ranked for ~70+% of the primary keywords in clusters A, B, C, D.

## Quality bar

Every post must:

1. Cite at least 5 primary sources (UPSC notification, NBE bulletin,
   NFHS-5, WHO, ICMR, NLEM, RNTCP, Surviving Sepsis, Williams, Harrison,
   Bailey, Park, ACLS, etc.).
2. Have a `personSchema` author block + `reviewedBy` block.
3. Surface a TOC + revision log + reference list.
4. Have an honest help-first CTA — never "Sign up now" — pointing to a
   real CrackCMS asset (PYQ bank, simulator, AI tutor, related guide).
5. Be ≥ 1,800 words. The two V1 posts are 3,000+ because they target
   the highest-intent late-prep keywords; evergreen posts can be 1,800.

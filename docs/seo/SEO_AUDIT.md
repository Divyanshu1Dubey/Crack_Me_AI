## 2. Metadata

### Title tags
All public pages now have unique, keyword-rich titles. The root layout sets a template `%s | CrackCMS` so page-specific titles always include the brand.

### Meta descriptions
- Length: 120–160 characters (optimal Google snippet range).
- Every description includes the primary keyword, benefit, and CTA.
- No duplicates across pages.

### Canonical URLs
Every public page sets `alternates.canonical`. The root layout defaults to `/`.

### OpenGraph + Twitter cards
Every public page includes:
- `og:type`, `og:title`, `og:description`, `og:url`, `og:image`, `og:site_name`
- `twitter:card="summary_large_image"`, `twitter:title`, `twitter:description`, `twitter:image`

OG image: `/cms-circle-logo.png` (1200×630 PNG).

### Robots directives
Root layout sets `index: true, follow: true, max-snippet: -1, max-image-preview: large, max-video-preview: -1`. Private routes are explicitly disallowed in `robots.ts`.

## 4. Technical SEO

### Sitemap
`/sitemap.xml` (auto-generated by `src/app/sitemap.ts`) now contains 30 routes with:
- `lastModified`
- `changeFrequency` (weekly for landing pages, monthly for guides, yearly for legal)
- `priority` (1.0 for home, 0.95 for exam landing pages, 0.9 for guides)

### Robots
`/robots.txt` (auto-generated by `src/app/robots.ts`) now allows all major search engines + 9 AI crawlers:
- GPTBot, ChatGPT-User, OAI-SearchBot (OpenAI)
- Claude-Web, ClaudeBot (Anthropic)
- PerplexityBot, Perplexity-User
- Google-Extended (Google AI Mode + Search Generative Experience)
- Applebot-Extended (Apple Intelligence)
- cohere-ai

Question bank, dashboard, and AI tutor are explicitly disallowed for AI crawlers to protect licensed content.

### URL structure
All public URLs are clean, lowercase, hyphen-separated:
- `/cms`, `/neet-pg`, `/ini-cet`, `/fmge`, `/usmle`, `/medical-officer`
- `/guides/upsc-cms-complete-guide`
- `/privacy-policy`, `/terms`, etc.

No URL parameters on canonical public routes.

### Hreflang
Root layout and all legal/guide/landing pages include:
- `en-IN` (primary)
- `en-US`
- `en-GB`
- `x-default` → root

### Pagination
The `/questions` page uses standard query parameters (`?page=N`) and renders self-referencing canonical URLs. Recommended: add `<link rel="prev">` and `<link rel="next">` in a future iteration.

## 5. Core Web Vitals

| Metric | Status |
|---|---|
| LCP | `<2.5s` on landing pages (font preload + lazy hero image) |
| INP | `<200ms` on interactive elements (Server Components for landing/legal pages) |
| CLS | `<0.1` (skeleton placeholders for dynamic content) |
| TTFB | `<400ms` (Render + Vercel edge cache) |

### Image optimisation
- `next/image` is used throughout (Next.js auto WebP/AVIF).
- Logo / hero images have explicit width/height to prevent CLS.

### Font loading
- `Manrope` + `Space_Grotesk` via `next/font/google` with `display: swap` + `latin-ext` subset to fix mojibake.
- Self-hosted at build time — no external font request.

### JS bundle
- Landing pages use Server Components where possible (zero client JS for legal pages).
- Client components lazy-loaded via `dynamic()` (ThemeToggle, ExamCountdown).

### Caching
- Service worker (`/sw.js`) for offline question bank.
- PWA manifest with shortcuts to CMS / NEET PG / AI Tutor / Mock Tests.

## 6. Content Strategy

### Long-form guides
Eight comprehensive guides (6–12 min read each) covering:
1. UPSC CMS Complete Guide 2026 — 3,000 words, syllabus, eligibility, pattern, books, cutoff, study plan
2. NEET PG Complete Guide 2026 — 3,000 words, AIR prediction, image-based questions
3. INI-CET Complete Guide — AIIMS / PGIMER / JIPMER specifics
4. FMGE Complete Guide — Indian-context preparation
5. USMLE Step 1 Guide for Indian MBBS Students — IMG-specific
6. Medical Officer Jobs Guide — central + state posts
7. AI in Medical Education — AI-tutor explainer
8. Build a Study Plan — actionable framework

Each guide includes:
- Author + last updated + reading time
- Table of contents (implicit via H2 headings)
- FAQ block with FAQPage schema
- Internal links to other guides + landing pages
- CTA back to CrackCMS product

### Trust / E-E-A-T signals
- `/about` lists named team members with roles + bios
- `/editorial-policy` documents sourcing + review workflow
- `/medical-review-policy` documents clinician reviewers
- `/disclaimer` discloses AI limitations
- All author + publisher details in Article schema

### FAQ optimisation (AEO)
Every landing page + guide has 6–10 expandable FAQ items targeting People Also Ask queries. Each FAQ answers in 1–3 sentences so AI engines can extract direct answers.

## 9. AI Crawler Optimisation (GEO)

- GPTBot, ChatGPT-User, OAI-SearchBot
- Claude-Web, ClaudeBot
- PerplexityBot, Perplexity-User
- Google-Extended

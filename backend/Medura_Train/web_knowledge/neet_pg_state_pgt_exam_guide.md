# NEET PG & State PGT Exam — Comprehensive Guide

## 1. NEET PG Overview

### Exam Structure (2024 Pattern)
- **Conducting Body**: National Board of Examinations (NBEMS)
- **Format**: Computer-Based Test (CBT)
- **Total Questions**: 200 MCQs (reduced from 300 in 2024)
- **Duration**: 3 hours 30 minutes
- **Marking**: +4 for correct, -1 for wrong
- **Eligibility**: MBBS degree + completion of 1-year internship
- **Exam Frequency**: Once a year (typically August-September)

## 2. NEET PG Counselling Process

### All-India Quota (AIQ) Counselling
1. **Round 1**: Choice filling → Allotment → Reporting
2. **Round 2**: Remaining seats → Choice filling → Allotment
3. **Mop-up Round**: Leftover seats
4. **Stray Vacancy**: Final round for unfilled seats

### State Quota Counselling
- Conducted by respective state counselling authorities
- 50% seats in government colleges reserved under state quota
- Domicile/nativity requirements vary by state
- Some states have additional entrance tests (e.g., JIPMER, AIIMS — now merged)

### Key Counselling Tips
1. Always keep a realistic preference list
2. Don't fixate on one branch — keep backup options
3. Research hospital reputation, not just college name
4. Consider bond obligations in different states
5. Check previous year allotment data for realistic expectations

## 3. Popular PG Branches & Competitiveness

### Most Competitive (High Cutoff)
1. **Dermatology** — Consistently highest cutoff, lifestyle-friendly
2. **Radiology** — Growing demand, AI-integration opportunities
3. **General Medicine** — Broad scope, academic prestige
4. **Ophthalmology** — Short procedure times, high ROI

5. **General Surgery** — Foundation for superspecialty
6. **OBG** — High clinical load, good private practice
7. **Pediatrics** — Rewarding, community-focused
8. **Orthopedics** — Procedure-heavy, good income potential
9. **ENT** — Balanced lifestyle and procedures

### Less Competitive but Rewarding
10. **Anesthesia** — Critical care pathway, ICU opportunities
11. **Psychiatry** — Growing relevance, less competitive
12. **Community Medicine / PSM** — Academic career, public health
13. **Forensic Medicine** — Niche, academic opportunities
14. **Pathology** — Diagnostic cornerstone, research-friendly

## 4. State PGT (Post Graduate Training) Exams

### Major State-Level PG Entrance Exams
- **UPPGMET** (Uttar Pradesh): Conducted by KGMU/ABVIMS
- **WBPGMAT** (West Bengal): Conducted by WBUHS
- **TNPG** (Tamil Nadu): Through state medical selection board
- **APPG** (Andhra Pradesh/Telangana): State counselling based on NEET PG
- **Karnataka PGCET**: State entrance for Karnataka domicile candidates
- **Maharashtra CET**: For state quota PG seats

### State Exam vs NEET PG
| Feature | NEET PG | State PGT |
|---------|---------|-----------|
| Scope | All-India seats | State-specific seats |
| Exam Body | NBEMS | State medical universities |
| Seats | 50% AIQ | 50% state quota + private |
| Bond | Usually none for AIQ | Varies (1-5 years in some states) |
| Cutoff | Higher | Generally lower |

## 5. UPSC CMS vs NEET PG — Career Comparison

### UPSC CMS Path
- **Career**: Central Health Services (Group A)
- **Starting Level**: Junior Scale (equivalent to Assistant Professor)
- **Promotions**: Time-bound + merit-based
- **Posting**: Central Government hospitals, CGHS, Railways, ESIC
- **Salary**: 7th Pay Commission (₹56,100 base + allowances)
- **Superspecialty**: Can pursue while in service (limited seats)
- **Job Security**: Permanent government service

### NEET PG Path
- **Career**: Clinical specialist / Academic
- **Starting**: Resident doctor → Senior resident → Consultant
- **Income**: Variable (₹80K-₹5L/month depending on branch/location)
- **Flexibility**: Private practice options after residency
- **Growth**: Superspecialty → Fellowship → Head of Department
- **Job Security**: Depends on employment type (government vs private)

### Dual Preparation Strategy
Many aspirants prepare for both simultaneously:
1. **Common Syllabus**: 70% overlap between CMS written and NEET PG
2. **Different Focus**: CMS emphasizes PSM/preventive medicine; NEET PG is more clinical
3. **Timeline**: NEET PG (Aug-Sep) and CMS written (Nov-Dec) are close
4. **Recommendation**: Start with NEET PG prep, add CMS-specific topics later

## 6. Preparation Strategy for NEET PG

### Phase 1: Foundation Building (6-8 months)
- Complete one standard textbook per subject
- Focus on understanding concepts, not memorizing
- Start a question bank (Marrow/PrepLadder/DAMS)

### Phase 2: Revision + QBank (3-4 months)
- Subject-wise revision with notes
- 100-150 MCQs daily from question banks
- Analyze wrong answers thoroughly

### Phase 3: Grand Tests + Weak Areas (2-3 months)
- Weekly full-length mock tests (200 questions)
- Focus on weak subjects identified from tests
- High-yield topic revision

### Phase 4: Final Sprint (1 month)
- Rapid revision of high-yield topics
- Image-based questions practice
- Previous year question patterns
- Time management optimization
